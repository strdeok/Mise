# 모바일 UI 방향

Mise의 MVP-0 화면 구현에 적용하는 모바일 UI 원칙이다. 이 문서는 화면 구조와 상호작용의 기준이며, 도메인 규칙과 데이터 계약을 바꾸지 않는다.

## 공통 원칙

- 흰 배경, 검은 주요 행동, 회색 구분선을 기본으로 사용한다. 일정·집중 시간·분석에는 파랑, 초록, 보라, 주황, 빨강의 옅은 배경과 진한 왼쪽 선을 제한적으로 쓴다. 색은 상태를 보조하며, 텍스트·아이콘·채움도 함께 제공한다.
- 모바일 한 손 조작을 기준으로 하단 탭과 주요 버튼에 충분한 터치 영역을 둔다.
- Safe Area를 포함해 상단의 맥락 정보와 하단의 탭 바가 겹치지 않게 배치한다.
- 정보는 카드의 반복보다 제목, 얇은 구분선, 여백으로 계층을 만든다.
- 입력·설정·상세 모달은 둥근 플로팅 패널(28px 모서리, 좌우 여백, 약한 그림자)로 통일한다. Todo 행 메뉴는 해당 행 옆에 열리는 둥근 팝오버를 유지한다.
- 펼침 화살표는 글리프 대신 고정 20×20 벡터를 사용한다. 상태는 방향과 접근성 expanded 값으로 함께 전달한다.
- 키보드가 열린 입력 패널은 Safe Area와 키보드 회피 영역 안에서 스크롤된다.

## 2026-10-11 시각 리프레시

- Today는 날짜와 작은 주간 맥락, `지금 할 일`, `다음 일정`, 오늘 Todo 순으로 배치한다. 가장 먼저 보이는 집중 카드는 연결된 Todo와 시작 행동을 함께 보여 준다.
- Todo는 프로젝트 계층을 유지하고, 부모와 자식의 누적 집중 시간을 행 오른쪽에서 읽을 수 있게 한다. 입력과 수정은 제목을 먼저 보여 주고, 나머지 선택값을 아래로 확장한다.
- Schedule은 종이 시간표처럼 시간축 위에 계획 블록을 놓는다. 블록마다 고유한 옅은 색 면과 선을 사용하고, 실제 시간은 별도 기록으로 구분한다.
- Timer는 케이스 카드 안에 넣지 않는다. 크림색 중심 노브와 빨간 진행 면을 가진 아날로그 다이얼, 그 아래 큰 디지털 시간, 원형 주요 제어로 구성한다. 전체화면에서도 같은 구조를 확대한다.
- Calendar는 월간 밀도 점과 선택 날짜의 의제를 함께 보인다. Stats는 큰 집중 합계, 계획 대비 차이, Todo별 색 막대로 회고한다.
- Settings는 테두리 카드의 반복 대신 목적별 섹션과 행을 사용한다. 추가·수정은 넓은 둥근 패널에서 빠르게 끝낼 수 있게 한다.

## 화면별 패턴

| 화면 | 적용 패턴 | 사용자 행동 |
| --- | --- | --- |
| Today | 지금 할 일과 다음 일정 중심 브리핑 | 검은 집중 카드에서 바로 Focus를 시작하거나 진행 중인 타이머를 연다. |
| Todo | 제목부터 적는 빠른 입력과 날짜 달력 | 기본 날짜를 요약하고, 필요할 때 날짜·카테고리·상위 Todo를 펼친다. 수정 시 기존 상세 정보를 표시한다. |
| Schedule | 월간 기본, 주간·일간 전환 | 달력에서 날짜를 고르고, 시간표에서 계획을 배치한다. |
| Timer | 별도 페이지에서 아날로그 다이얼 표시, 상단 설정 버튼에서 Focus·Short Break·Long Break·간격 조정 | 시간은 다이얼 아래에서 읽고, Focus와 휴식 순서를 한눈에 확인한다. 시작 전에는 선택한 Todo를 보여준다. |
| Stats | 계획 대비 실제 시간 회고 | 기간을 바꾸며 계획 안·밖의 집중 시간과 Todo별 사용 시간을 비교한다. |

## 레퍼런스 해석

- Things와 Structured의 조용한 Today 흐름을 참고해, 하루의 목록보다 현재 할 일을 먼저 보인다.
- Todoist Quick Add처럼 제목 입력을 먼저 열고, 선택값은 점진적으로 노출한다.
- Structured·Routine·Notion Calendar의 달력과 시간표 전환 구조를 참고한다.
- Session의 시각 타이머 표현과 Sunsama의 계획 대비 실제 회고를 Mise의 흑백 토큰으로 재해석한다.

## 리서치 보완 적용

- Today의 집중 합계와 계획은 작은 한 줄 요약으로 보조하며, 현재 할 일과 집중 행동을 우선한다. 할 일이 없는 첫 화면의 행동은 Todo 추가로 연결한다.
- 월간 일정은 날짜별 최대 3개의 점으로 일정 밀도를 표현한다.
- 주간 시간표는 가로 스크롤 없이 7열을 유지한다. 블록의 짧은 제목은 한 줄로 표시하고, 선택한 블록의 제목과 시간은 시간표 아래에 표시한다. 해당 날짜의 하루 보기로 이동할 수 있다.
- Stats는 계획보다 초과·미달한 시간을 직접 표시한다. 계획이 없으면 별도 문구를 사용한다.

## 타이머 페이지와 집중 전체화면

- `/timer`는 시트 모달이 아닌 전체 페이지로 연다. 뒤 화면의 축소·딤·상단 시트 여백이 보이지 않는다.
- 일반 화면에서는 기존 타이머 케이스와 설정·전체화면 버튼을 유지한다.
- 전체화면은 [Session 모바일 타이머](https://www.stayinsession.com/iphone-timer.png)의 배경 위 다이얼·여백·분리된 시간 표기를 참고한다. 전체화면 진입은 테마를 바꾸지 않는다. 배경·시계·글자·버튼은 앱 공통 palette와 상태바 설정을 따른다. 현재 앱은 밝은 테마를 사용한다.
- 전체화면 다이얼에는 케이스·테두리·그림자를 두지 않는다. Todo 제목·디지털 시간·상태는 다이얼 밖에 표시하고, 시작/일시정지/재개와 완료는 하단에 배치한다.
- 전체화면은 세션의 상태나 시간을 변경하지 않는다. 축소 및 Android 뒤로가기는 먼저 일반 타이머로 돌아간다. 시스템 상·하단 영역과 가로 화면을 고려한다.

## 검증 기준

- 360px와 390px 폭에서 제목, 시간, Todo 행의 텍스트가 잘리지 않는다.
- 선택·진행·완료 상태는 아이콘, 텍스트, 채움으로 구분한다.
- iOS와 Android에서 Safe Area, 키보드, Modal, 뒤로가기 후에도 주요 행동이 가려지지 않는다.
