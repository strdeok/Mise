# Todo와 Today

**우선순위:** P0. **목적:** 장기 작업 구조와 오늘 할 일을 분리해, 오늘 작업을 바로 확인하고 Focus를 시작한다.

## 사용자 시나리오와 입출력

사용자는 Todo를 생성·수정·정렬·완료·삭제하고 특정 날짜의 오늘 할 일로 지정한다. Today는 날짜, 총 Focus 시간, 현재 세션, 다음 Schedule Block, Todo별 기록 시간·완료·배치 여부를 보여준다. Todo 생성 입력은 필수 `title`, 선택 `description`, `parentId`, `categoryId`, 오늘 포함 여부다.

Today의 오늘 날짜는 현재 사용자 기기 시간대 기준이다. 과거 기록은 저장 당시 시간대와 현지 날짜를 보존하며, 기기 시간대가 변경되면 당시 기준 시간대를 함께 보여준다.

## 정상 흐름

- 부모가 없으면 depth 0, 자식은 최대 depth 2까지 허용한다. Todo와 오늘 지정(`todo_days`)은 별도 데이터다.
- 카테고리는 계층과 독립적이다. Todo에는 카테고리를 하나 선택하거나 지정하지 않을 수 있다. 상위 Todo의 카테고리를 하위 Todo에 자동 상속하지 않는다. 등록·수정 화면에서 카테고리를 선택하거나 새로 만들 수 있고, 목록·상세·Today에는 흑백 배지로 표시한다. 전체 Todo 목록에서 카테고리 및 미분류 필터를 제공한다.
- 등록·수정 화면은 선택한 상위 Todo와 카테고리만 한 줄씩 보여준다. 각 항목을 누르면 검색 가능한 선택 시트가 열리며 `없음`을 선택할 수 있다. 전체 Todo의 카테고리 필터 칩은 가로로 넘길 수 있지만 스크롤 막대는 표시하지 않는다.
- Today와 전체 Todo의 `···`는 웹·iOS·Android 공통 작업 시트를 연다. Today에서는 수정·오늘에서 제외·삭제를, 전체 Todo에서는 수정·하위 Todo 추가·순서 변경·보관/복원·삭제를 제공한다. 삭제 전에는 하위 Todo 수와 기록 처리 방식을 보여주고 확인을 받는다.
- 카테고리 이름은 공백을 제외한 값이어야 하며 같은 사용자의 카테고리 이름은 대소문자 구분 없이 중복할 수 없다. 이름 변경은 연결된 Todo 배지에 즉시 반영한다. 카테고리 삭제는 연결된 Todo를 미분류로 바꾸며 Todo·Focus 기록을 삭제하지 않는다.
- 부모·순서 변경은 App이 `parentId`와 원하는 `orderIndex`만 보내고, 서버가 트리 검증·형제 순서 재정렬·동시 요청 직렬화를 처리한다. App은 성공 후 서버 목록을 다시 조회한다.
- 완료는 사용자가 직접 변경하며 취소할 수 있다. 상위·하위 Todo의 완료 상태는 독립적이다. 미완료 하위 Todo가 있어도 상위를 완료할 수 있고, 상위를 완료하거나 다시 미완료로 바꿔도 하위 상태는 바뀌지 않는다. 세션이나 계획 시간이 끝나도 자동 완료하지 않는다.
- 삭제는 확인 후 해당 Todo와 모든 하위 Todo를 hard delete한다. 확인 화면에 함께 삭제될 하위 Todo 수를 안내한다. 과거 완료 Focus 세션과 통계는 보존한다.
- Today에서 Todo 생성, 완료 변경, 상세 진입, Focus 시작, Schedule 이동이 가능하다.
- 오늘 할 일 지정·해제 시 기기에서 계산한 `date`와 `timezoneId`, 선택 상태를 API Body로 전달한다. 동일한 요청을 반복해도 지정 상태가 중복되지 않는다.

## 예외·권한

공백 제목, 순환 부모, 다른 사용자의 부모, 하위 노드가 depth 2를 넘는 이동은 거부한다. 삭제 대상 트리의 어느 Todo에라도 활성 Focus가 연결돼 있으면 삭제를 거부한다. 서버가 모든 계층·소유권 제약을 재검증한다. 세션에는 Focus 시작 당시 Todo 제목·경로를 보존한다. 살아 있는 Todo의 과거 기록은 현재 프로젝트 위치로 집계하고, 삭제 직전에 해당 트리의 최종 경로를 완료 Session에 저장해 삭제 후 통계를 그 위치에 고정한다. 삭제 후 기록에는 `삭제된 Todo · 당시 제목`을 표시한다. MVP에는 삭제 취소 기능이 없다.

규칙 `TODO-01`~`TODO-07`, `STATS-01`, API `/todos*`, 인수 기준 `AC-TODO-*`를 참조한다.
