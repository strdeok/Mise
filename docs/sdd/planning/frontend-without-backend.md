# 백엔드 없이 가능한 프론트엔드 범위

이 문서는 네트워크·서버 계정·API 없이 기기 안에서 처리할 수 있는 기능을 정리한다. 데이터의 기준 저장소는 AsyncStorage Repository이며, 기기 변경·재설치·다른 기기 동기화는 범위 밖이다.

## 이미 구현됨

- 인증 없이 mock 사용자로 Today 진입
- AsyncStorage 기반 Todo, Schedule, Session, Settings 저장과 샘플 데이터 초기화
- Focus, Short Break, Long Break 시작·일시정지·재개·완료·폐기
- 앱 백그라운드·재시작 후 저장 시각으로 경과 시간 복원
- 목표 초과 계속 기록, 목표 시간 저장, 실제 시간 직접 수정
- 오늘 Todo 생성·완료·Today 지정·삭제와 활성 Focus Todo 삭제 차단
- 하루 단위 Schedule 생성·수정·삭제, Todo 연결, 시간 겹침 검증
- iOS·Android 기기 기본 시간 선택기
- 로컬 종료 알림 예약·취소·재시작 시 중복 정리
- 주간·월간 Focus·Break, 계획 대비 실제, Todo별 시간 통계
- 삭제 Todo·Schedule의 스냅샷으로 완료 기록과 통계 보존

## Todo와 Today

- Todo 제목 수정
- 부모 선택으로 3단계 Todo 생성
- Todo의 부모 변경과 순서 변경
- 드래그 앤 드롭 정렬
- 오늘 목록과 전체 목록 분리, 날짜별 Today 지정
- 완료·미완료 필터, 검색, 정렬
- Todo별 누적 시간·최근 기록·예정 블록 표시
- Todo 복제, 보관, 로컬 복원
- 삭제 전 확인, 최근 삭제 항목의 로컬 되돌리기
- 빈 상태, 오류 상태, 첫 사용 안내

## Schedule

- 일·주 단위 타임라인과 날짜 이동
- 시간축에 블록 위치와 현재 시각 표시
- 블록 제목·시간·Todo 연결 수정
- 긴 블록 분할, 복제, 다음 날 복사
- 블록 색상과 카테고리 라벨
- Todo별 일정 필터, 완료 Todo 숨기기
- 충돌 위치 미리보기와 저장 전 즉시 오류 표시
- 블록에서 Todo를 연결하고 Focus를 바로 시작
- 일정 없는 Focus를 계획 외 기록으로 표시
- 로컬 반복 일정 생성 규칙(매일·평일·매주)과 향후 날짜 인스턴스 생성
- 로컬 휴일·주말 표시

## Timer와 세션 기록

- 기본 Focus·Short Break·Long Break 시간 설정
- 카운트다운·경과 시간 표시 전환
- 세션 화면의 Todo·Schedule 정보, 진행률, 목표 초과 상태
- Pause 상태를 포함한 단일 활성 세션 제한
- Focus 완료 후 다음 Break 시작 제안
- Break 완료 후 Focus 시작 제안
- 세션 완료 시 실제 측정·목표 시간·직접 입력 중 기록 방식 선택
- 완료된 세션의 로컬 편집·삭제·되돌리기
- 세션 기록 목록, 날짜·Todo·유형 필터, 검색
- 앱 종료·재실행·기기 시간대 변경 시 기록의 원래 시간대와 현지 시간 표시
- 세션 중 화면 유지, 진동·사운드·화면 내 종료 안내
- Apple Health·Android Health Connect 같은 기기 단말 API 연동은 서버 없이도 가능하지만 별도 네이티브 권한과 개발 빌드가 필요함

## 알림과 기기 통합

- 알림 권한 상태 표시와 재요청 안내
- 종료 알림, 알림 탭 시 Timer 화면 열기
- Focus·Break별 알림 토글과 알림 문구 설정
- 앱 재시작 시 예약 알림과 활성 세션의 일치 검사
- Android Notification Channel 설정
- 로컬 일일 리마인더·일정 시작 전 알림
- 앱 아이콘 배지, 진동, 사운드 선택
- iOS·Android 홈 화면 위젯
- Android Quick Settings 타일·앱 바로가기
- iOS Live Activity·Dynamic Island, Android ongoing notification
- 공유 시트로 텍스트를 Todo로 생성
- 딥 링크로 특정 Todo·날짜·Timer 화면 열기

## Stats와 회고

- 일·주·월·사용자 지정 기간 이동
- Focus·Break 합계, 세션 수, 완료율
- Todo 직접 시간·하위 Todo 포함 시간·프로젝트 합계
- 계획 시간·계획 내 실제·계획 외 실제·편차
- 날짜별·요일별·시간대별 집중 분포
- 주간 추이, 월간 캘린더 히트맵, 목표 달성률
- 완료·미완료·삭제 Todo를 스냅샷 기준으로 함께 표시
- 로컬 목표 시간과 연속 집중 일수
- 통계 화면 이미지·CSV·공유 텍스트 내보내기
- 기기 로컬 PDF 리포트 생성 및 공유

## 설정과 제품 경험

- 한국어·영어 등 앱 내 언어 전환
- 라이트·다크·시스템 테마
- 글자 크기, 고대비, 스크린 리더 레이블, 터치 영역 확대
- 주 시작 요일, 시간 표기, 기본 일정 간격 설정
- 모든 로컬 데이터 내보내기·가져오기(JSON)
- 로컬 데이터 전체 삭제
- 온보딩, 기능 소개, 변경 이력
- 앱 버전·오픈 소스 라이선스·개인정보 안내 화면
- 개발자용 fixture 선택·데이터 검사 화면

## 백엔드가 필요한 기능

- Google·Kakao·Apple OAuth와 계정 연결
- 여러 기기 간 동기화, 백업, 충돌 해결
- 팀·공유 프로젝트·공동 일정·다른 사용자 초대
- 서버 푸시 알림과 원격 설정
- 웹·데스크톱과 동일 데이터 사용
- 계정 기반 결제·구독·영수증 서버 검증
- 계정 삭제와 보관 정책
- 서버 분석, 원격 오류 수집, 관리자 기능

## 구현 우선순위

1. Todo 편집·계층·정렬과 전체 Todo 화면
2. 주 단위 타임라인, 반복 일정, 블록 복제
3. 세션 기록 목록과 완료 기록 편집
4. Stats의 추이·히트맵·내보내기
5. 일일 리마인더, 위젯, Live Activity·ongoing notification
6. 다크 모드·접근성·언어·로컬 백업/복원
