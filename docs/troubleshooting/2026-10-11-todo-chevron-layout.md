# Todo 펼침 화살표 비율과 팝업 형태

## 증상

Todo 하위 목록을 펼치면 화살표가 찌그러져 보이고, 입력·설정창이 각진 카드처럼 보였다.

## 재현 방법

할 일 화면에서 하위 Todo가 있는 항목의 펼침·접기 버튼을 누른다. Todo 등록이나 타이머 설정 모달을 연다.

## 원인

펼침 표시는 서로 형태와 기준선이 다른 `›`, `⌄` 글자를 사용했다. 폰트 크기와 lineHeight 보정으로는 일관된 비율을 보장하지 못했다. 팝업도 화면 안의 작은 카드와 같은 Card 모서리 토큰을 사용했다.

## 해결

20×20 SVG Chevron으로 방향을 바꾸고 버튼의 크기와 축소 방지를 지정했다. 팝업은 별도 SheetCard로 분리해 28px 모서리와 여백·그림자를 적용했다. 카테고리 선택의 중첩 텍스트에도 세로 flex가 적용돼 위로 붙는 문제를 함께 수정했다.

## 검증

iOS Simulator에서 펼침·접기, Todo 등록과 상세 옵션, 주간 일정 선택 표시를 확인했다. TypeScript 및 Web export로 빌드를 검증한다.
