# UI 조사에서 발견한 재현 가능 문제와 남은 QA

## 1. 일정 시간 변환과 자정 종료 처리

### 증상

기존 분 변환식은 09:30을 2730분(45:30)으로 만들었다. 종료 시각 24:00은 DateTimePicker의 자정 00:00과 구분되지 않았다.

### 재현 방법

기존 식 기준 09:30 계산은 `Math.floor(9 * 60 + 30 / 5) * 5 = 2730`이었다. 일정 폼에서 시간 선택을 완료한다.

### 원인

5분 정리 전에 시·분 전체를 합산하지 않았고, 하루 종료를 분 값 1440으로 보존하지 않았다.

### 해결

전체 분을 5로 나누어 반올림한 뒤 다시 5를 곱한다. 종료가 자정이면 1440(24:00)으로 기록한다. 일정 충돌/시간 오류는 열린 일정 폼에 표시한다.

### 검증

변환식의 01:00→60, 09:30→570, 23:55→1435를 확인했고 TypeScript 및 Web export가 통과했다. iOS·Android picker에서 24:00 선택 및 취소는 사용자의 실제 기기 QA가 남아 있다.

## 2. Timer 직접 진입의 저장 데이터 복원

### 증상

Home에서만 hydrate를 호출해 `/timer` 직접 로드 또는 알림 진입에서 초기 빈 store가 보일 수 있었다.

### 재현 방법

기존 웹 재현: Home에서 Todo를 본 뒤 `/timer`를 새로 열면 목록이 0개였다. 알림 cold start는 소스에서 같은 가능성을 확인했으나 직접 재현하지 않았다.

### 원인

화면별로 초기화가 갈라져 root navigation이 데이터 준비를 기다리지 않았다.

### 해결

root가 한 번 hydrate한 뒤 화면과 알림 응답을 열도록 순서를 옮겼다. 기존 저장 payload의 해석 실패 때 저장값을 제거하지 않는다. 읽기 실패에는 재시도 화면을 제공한다.

### 검증

Expo Go iOS 시뮬레이터에서 앱이 root 준비 뒤 기존 Timer/Today 상태를 렌더링하는 것을 확인했다. 종료 상태의 로컬 알림을 눌러 cold start하는 QA와 손상된 payload 재시도 확인은 남아 있다.

## 3. 저장 실패 때 메모리와 화면이 먼저 성공 상태가 됨

### 증상

저장 함수가 Zustand 상태를 먼저 바꾸고 기기 저장소를 기다렸다. 쓰기가 실패하면 화면은 성공처럼 보일 수 있었다.

### 원인

화면 상태를 영구 저장보다 먼저 커밋했다.

### 해결

저장소 쓰기가 성공한 뒤 Zustand를 갱신한다. 실패하면 초안/기존 상태를 유지하고 오류를 store에 남겨 현재 폼에서 읽을 수 있게 한다.

### 검증

코드 경로와 TypeScript/Web export를 확인했다. 실제 저장소 실패 주입 테스트는 수행하지 않았다.

## 4. 웹 SVG 접근성 경고

### 증상

390×844 웹 미리보기에서 SVG의 `accessible={false}`가 DOM 속성 경고로 표시되어 하단 탐색을 가렸다.

### 재현 방법

웹 Todo 목록에서 Chevron이 든 상세/메뉴를 연다. 기존 조사에서 `frontend/src/components/chevron.tsx:7`을 확인했다.

### 원인

react-native-svg의 웹 SVG까지 네이티브 접근성 속성이 DOM 속성으로 전달되는 경로가 있다.

### 해결

미해결. 웹 개발 미리보기에서 재확인하고 web/native 속성 전달을 분기한다. production이나 native 제품 결함으로 일반화하지 않는다.

### 검증

수정 대상이 아니어서 재현 상태는 기존 조사에 기록된 관찰이다. 후속 변경 후 웹 개발 미리보기 경고를 확인한다.

## 5. 일정 블록 이동이 세로 스크롤을 가로챌 수 있음

### 증상

기존 PanResponder는 5px보다 큰 세로 이동을 곧바로 일정 드래그로 처리하고 손가락 이동마다 React state를 갱신했다.

### 원인

스크롤과 이동 제스처를 구분하는 명시적 의도 동작이 없었다.

### 해결

250ms 길게 눌러 활성화하는 Gesture Handler Pan으로 교체했다. 프레임 이동값은 Reanimated shared value로 그리며, 손을 뗄 때에만 Zustand 저장을 한 번 요청한다. 취소되거나 저장이 거절되면 이전 위치로 복귀한다.

### 검증

TypeScript 검사를 통과했다. 시뮬레이터에서 긴 누름·빠른 방향 전환·취소·충돌 복귀 감각을 확인하지 않았다. 스크롤과 5/10/15분 블록은 iOS·Android 실제 기기에서 QA한다.
