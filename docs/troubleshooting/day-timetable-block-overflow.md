# 일간 시간표 블록의 내용 겹침

## 증상

일간 보기에서 45분 일정의 제목·시간과 수정·집중·삭제 버튼이 블록 안에서 겹치고, 텍스트가 시간 눈금 밖으로 삐져나왔다.

## 재현 방법

일정 탭에서 일간 보기로 전환하고 45분짜리 Schedule Block을 확인한다.

## 원인

블록의 높이는 일정 시간에 비례하지만 내부에는 제목, 시간, 세 개의 조작 버튼을 항상 배치했다. 높이가 부족해도 내부 콘텐츠가 줄거나 숨겨지지 않았다. 최소 높이 32dp는 5분 블록이 인접 블록 위를 덮을 수도 있었다.

## 해결

블록에는 길이에 맞춰 제목과 시간을 표시하고, 조작 버튼은 블록 탭 시 열리는 메뉴로 옮겼다. 블록 높이는 일정 길이에 맞춰 그려 인접 블록을 덮지 않도록 했다. 드래그 이동용 PanResponder는 블록의 바깥 컨테이너에 유지했다.

## 검증

- 45분·60분 블록에서 텍스트가 겹치지 않는 것을 모바일 폭의 웹 미리보기에서 확인했다.
- 블록 탭 시 수정·집중 시작·삭제 메뉴가 열리는 것을 확인했다.
- `npx tsc --noEmit` 및 `npx expo export --platform web` 통과.
