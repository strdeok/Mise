# 타이머 시계 안의 시간 글자와 전체화면 버튼 배치

## 증상

아날로그 시계 안에 디지털 시간이 겹쳐 가독성이 낮았다. 전체화면에서는 시계가 커지면서 시작 버튼이 화면 아래로 밀렸다.

## 재현 방법

Today에서 Focus를 열어 시계를 확인하고, 전체화면을 눌러 낮은 화면 높이에서 하단 조작을 확인한다.

## 원인

시계 SVG 안에 시간 문자열을 배치했고, 전체화면 시계 크기를 화면 높이에서 180만 빼서 정했다. 아래쪽 시간 표시와 버튼의 높이를 충분히 고려하지 못했다.

## 해결

시간 문자열을 시계 아래로 이동했다. 전체화면의 정사각형 패널 크기는 화면 너비와 `화면 높이 - 300` 중 작은 값으로 제한하고, 높이가 부족하면 스크롤할 수 있게 했다.

## 검증

웹 미리보기에서 일반 화면과 전체화면을 확인했다. 높이 633px의 미리보기에서도 시계, 디지털 시간, 시작 버튼이 함께 보인다. 실제 기기 QA는 남았다.
