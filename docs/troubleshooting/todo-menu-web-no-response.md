# 웹에서 Todo 메뉴가 열리지 않음

## 증상

Today 또는 전체 Todo에서 `···`를 눌러도 웹 미리보기에 메뉴가 나타나지 않는다.

## 재현 방법

웹 미리보기에서 Todo의 `···`를 누른다. 기존 구현에서는 메뉴가 열리지 않는다.

## 원인

작업 목록을 React Native `Alert.alert`로 구성했다. 해당 API는 웹에서 네이티브 선택 메뉴를 표시하지 않는다.

## 해결

Today와 전체 Todo에서 공통 `Modal` 작업 시트를 사용한다. 삭제 확인도 같은 시트 안에서 표시한다. `···`의 터치 영역을 44dp 이상으로 지정한다.

## 검증

웹 미리보기에서 메뉴 열기, 삭제 확인, 닫기, 수정 시트 이동을 확인했다. iOS·Android 실제 기기의 모달 전환은 MVP 실기기 QA에서 확인한다.
