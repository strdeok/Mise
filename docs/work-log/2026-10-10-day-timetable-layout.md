# 2026-10-10 — 일간 시간표 블록 UI 수정

## 목표

일간 시간표에서 일정 블록의 텍스트와 조작 버튼이 겹치는 문제를 해결한다.

## 변경

- 시간표 블록에는 일정 길이에 맞춰 제목과 시간만 보여준다.
- 수정·집중 시작·삭제를 블록 탭 메뉴로 옮겼다.
- 5분 단위의 짧은 블록도 실제 시간 높이로 그리며, 인접 일정과 겹치지 않게 했다.
- 처음 보여주는 오전 시간대의 첫 시간 라벨이 잘리지 않도록 스크롤 위치를 조정했다.

## 검증

- 모바일 폭 웹 미리보기에서 일간 시간표와 블록 탭 메뉴를 확인했다.
- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과. Expo Notifications의 기존 웹 정적 렌더 경고가 표시된다.
- `cd frontend && npx expo export --platform android` 통과.
- `cd frontend && npm test -- --run`에서 기존 7개 테스트 통과.

## 남은 일

- 실제 기기에서 짧은 블록의 터치 영역과 드래그 이동을 확인한다.
