# 2026-10-10 — Refero 참고 UI 정리

## 목표

Today 목록, 일정 탐색, 타이머의 시각적 위계를 정리한다. 흑백 정책과 기존 기능을 유지하면서 작은 모바일 화면에서 읽기와 조작을 편하게 만든다.

## 변경

- 공통 배경·선·카드·버튼의 색과 모서리, 제목 굵기를 절제했다.
- Today와 Todo를 구분선 중심 목록으로 만들고 Focus 요약만 패널로 강조했다.
- 일정 헤더를 압축하고 월간 보기의 중복 월 표시를 제거했다. 주간·일간 시간표는 처음 열 때 오전 시간대를 보여준다. 활성 미니 타이머가 있을 때 스크롤 영역도 그 위에서 끝나도록 정리했다.
- 주간·일간 일정 블록을 밝은 면과 검은 왼쪽 표시선으로 통일했다.
- 타이머 다이얼을 화면 크기에 맞추고 디지털 시간을 다이얼 안으로 옮겼다. 짧은 화면에서는 전체 화면을 스크롤할 수 있다.
- Git ref에는 `:`를 사용할 수 없어 지침의 `feature:...` 대신 `feature/refero-ui-refresh` 브랜치를 사용했다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과. Expo Notifications의 기존 웹 정적 렌더 경고가 표시된다.
- 웹 미리보기 390×844 및 360×640에서 Today, 월간·주간 시간표, Timer 배치를 확인했다.
- `cd frontend && npm test -- --run`에서 기존 7개 테스트가 통과했다.
- `cd frontend && npx expo run:android`로 디버그 앱을 빌드해 에뮬레이터에 설치했다.
- iOS 시뮬레이터 빌드는 CocoaPods 설치 단계에서 진행되지 않아 중단했다. iOS 화면은 이번 작업에서 확인하지 못했다.

## 남은 일

- iOS 빌드의 CocoaPods 설치를 해결하고, iOS·Android 실제 기기의 글자 크기 확대, 주간 좁은 블록의 제목 읽기, 타이머 조작부를 사용자 QA에서 확인한다.
