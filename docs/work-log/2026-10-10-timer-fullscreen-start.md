# 2026-10-10 — 타이머 가독성과 명시적 시작

## 목표

아날로그 시계와 디지털 시간을 분리하고, 전체화면에서 시계를 크게 표시한다. 타이머 화면 진입만으로 기록이 시작되지 않게 한다.

## 변경

- Time Timer의 전체화면 타이머와 iPhone 시계 앱의 시작 버튼 흐름을 참고했다.
- 디지털 시간을 시계 아래로 옮기고, 전체화면에서는 화면 크기에 맞춘 정사각형 시계 패널과 큰 시간 표시를 사용한다.
- Session에 `ready` 상태를 추가했다. 화면 진입 시 준비 상태를 저장하고 `시작`을 눌렀을 때 시작 시각·날짜·시간대를 기록한다.
- 준비 상태를 미니 타이머에 `시작 전`으로 표시하고, 알림 예약과 완료·일시정지는 시작 이후에만 허용한다.
- 상태 전이와 화면 규칙을 SDD에 반영했다. 새 의존성은 추가하지 않았다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npm test -- --run` 통과(8개 테스트).
- `cd frontend && npx expo export --platform web` 통과.
- 웹 미리보기에서 준비 상태, 전체화면 버튼 노출, 시작 뒤 카운트다운, 일시정지, 테스트 기록 폐기를 확인했다.
