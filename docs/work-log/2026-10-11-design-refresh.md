# 2026-10-11 — 모바일 디자인 리프레시

## 목표

첨부 시안의 정보 밀도와 시각 계층을 MVP-0 화면에 적용한다. Today의 시작 행동, 일정의 시간표 구분, 타이머의 아날로그 표현, 통계의 계획 대비 회고를 우선한다.

## 변경

- 공통 palette에 일정·분석·타이머 전용의 제한된 포인트 컬러와 옅은 배경 토큰을 추가했다.
- Today에 주간 날짜 맥락과 큰 집중 시작 카드를 추가했다.
- Schedule의 월간 점, 일간 블록, 주간 블록을 일관된 블록 색으로 표시했다.
- Timer에서 사각형 케이스를 제거하고, 빨간 진행 면과 크림색 노브의 아날로그 다이얼 및 원형 제어를 적용했다.
- Stats에 초록색 계획 대비 요약과 Todo별 색 막대를 적용했다.
- Settings를 목적별 설정 행으로 묶어 카드 반복을 줄였다.
- 모바일 UI 방향 문서에 색 사용 규칙과 화면별 리프레시 기준을 기록했다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과
- `cd frontend && npx expo export --platform web` 통과

## 남은 일

- iOS·Android 실기기에서 Timer 다이얼, 주간 일정의 작은 블록, Settings Switch의 여백을 확인한다.
- Todo 계층별 누적 집중 시간과 기록 상세 화면은 실제 데이터 흐름을 함께 검토해 다음 디자인 작업으로 추가한다.
