# 2026-10-11 — iOS 디자인 스냅샷 아카이브

## 목표

현재 MVP-0 디자인을 화면별로 기록해 UI 변경 전후 비교와 실기기 QA의 기준으로 남긴다.

## 변경

- iPhone 17 Pro Simulator에서 Today, Todo, 일정 월·주·일, 통계, 타이머 일반·전체화면, 앱 설정, 타이머 설정 패널을 캡처했다.
- 화면별 PNG와 캡처 환경을 `docs/design-snapshots/2026-10-11-ios`에 기록했다.
- 같은 폴더를 ZIP으로 묶어 공유 가능한 아카이브를 만들었다.

## 검증

- 10개 PNG의 형식과 ZIP 파일 목록을 확인했다.
