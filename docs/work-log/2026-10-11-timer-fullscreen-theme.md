# 2026-10-11 — 전체화면 타이머 테마 수정

## 목표

전체화면 진입 시 강제로 어두운 테마로 바뀌는 동작을 없애고 앱 설정을 따른다.

## 변경

- 전체화면 전용 검은 배경과 밝은 상태바 강제 설정을 제거했다.
- 다이얼·눈금·제목·시간·버튼을 앱 공통 palette에 연결했다. 현재 앱의 밝은 배경과 검은 시계를 사용한다.
- 이전 작업의 Session 참고 배치와 전체 페이지 전환은 유지했다. 별도의 테마 설정이나 의존성은 추가하지 않았다.

## 검증

- TypeScript 검사 및 Web export 통과. 기존 알림 패키지의 Web 서버 렌더링 경고는 남아 있다.
- iOS Simulator에서 전체화면의 밝은 배경과 시계·시간·버튼의 대비를 확인했다.

## 남은 일

- Android 실제 기기의 시스템 표시 영역은 사용자 QA에서 확인한다.
