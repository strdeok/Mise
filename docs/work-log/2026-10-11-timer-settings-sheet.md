# 2026-10-11 — 타이머 페이지 설정 창

## 목표

추가한 하단 Timer 탭을 제거하고, 기존 타이머 페이지에서 설정 버튼을 통해 포모도로 시간을 조정한다.

## 변경

- 하단 탭은 Today·Todo·Schedule·Stats·Settings 구성으로 복원했다.
- Today·Todo·Schedule·미니 타이머에서 `/timer` 페이지를 연다.
- 타이머 상단의 `설정` 버튼은 준비 중·실행 중·전체화면·세션 종료 화면에서 제공한다.
- 설정 하단 시트에 집중, 짧은 휴식, 긴 휴식 시간과 긴 휴식 간격을 넣었다.
- 값을 조정한 뒤 저장해야 적용한다. 취소·닫기·Android 뒤로가기는 임시 변경을 버린다.
- READY 목표 시간은 설정 저장 시 함께 변경한다. 실행·일시정지 중인 목표 시간은 유지하며 다음 세션부터 변경된 시간을 적용한다.
- iOS Simulator에서 확인한 AsyncStorage 네이티브 모듈 오류를 해결하기 위해 기존 패키지를 Expo SDK 57 번들 지원 버전인 2.2.0으로 맞췄다. 새 의존성은 추가하지 않았다. 앱의 저장 API는 동일하며 네이티브 빌드는 다음 APK 생성 시 반영한다.
- 관련 SDD의 Timer 탭 표현을 별도 페이지와 설정 시트로 수정했다.

## 검증

- TypeScript 검사 및 Expo 웹 내보내기 통과.
- iOS Simulator: 기존 하단 5개 탭, 타이머 설정 열기, 네 항목 표시, 저장 후 창 닫힘 확인.
- iOS Simulator: 집중 시간을 임시로 25→26분 변경하고 취소한 뒤 재진입하면 25분 유지됨을 확인.
- 패키지 정렬 후 저장 시 네이티브 모듈 오류가 발생하지 않는 것을 확인했다.
