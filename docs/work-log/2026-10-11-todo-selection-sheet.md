# 2026-10-11 — Todo 선택 시트

## 목표

Todo 등록·수정 창의 가로 칩 목록과 눈에 띄는 스크롤 막대를 없애고, 상위 Todo와 카테고리를 찾기 쉽게 한다.

## 변경

- 상위 Todo와 카테고리는 현재 선택값만 한 줄로 표시한다.
- 한 줄 항목을 누르면 검색 가능한 선택 시트가 열린다. `없음` 선택, 선택 취소, Android 뒤로가기를 지원한다.
- 상위 Todo 검색 결과는 경로를 함께 표시하고 기존 3단계·순환 제한을 유지한다.
- 카테고리 선택 시트에서 새 카테고리를 생성하고 즉시 선택할 수 있다.
- 전체 Todo의 카테고리 필터는 가로 넘김을 유지하면서 스크롤 막대를 숨겼다.
- 새 의존성이나 데이터 모델 변경은 없다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npm test` 12개 통과.
- 웹 미리보기에서 등록 창, 상위 Todo 검색·선택, 카테고리 선택 시트를 확인했다.
- `cd frontend && npx expo export --platform web` 통과. iOS·Android 번들도 각각 생성됐다.

## 남은 일

- iOS·Android 실제 기기에서 긴 목록, 키보드가 열린 상태의 시트 스크롤과 뒤로가기를 확인한다. MVP 단계별 실제 기기 QA는 사용자가 진행한다.
