# 2026-10-11 — 팝업 디자인 복구와 레퍼런스 보완

## 목표

각진 팝업을 둥근 플로팅 패널로 변경하고, Todo 펼침 화살표의 비율을 고친다. 기존 모바일 UI 리서치에서 빠진 개선점을 반영한다.

## 변경

- Todo 등록·상세, 카테고리, 일정 메뉴·선택, 타이머 수동 입력·설정에 공통 SheetCard를 적용했다. 28px 모서리, 약한 그림자, 바깥 여백을 사용한다.
- Todo 행 메뉴는 앵커 팝오버를 유지하며 20px 모서리를 적용했다. 삭제 확인창도 공통 패널을 사용한다.
- SafeAreaSheet에 키보드 회피와 스크롤을 적용했다.
- Todo 펼침·선택·상세·행 메뉴 화살표를 고정 벡터로 바꿨다. 펼침 버튼에 expanded 접근성 상태를 추가했다.
- 빠른 Todo 입력은 제목과 기본 날짜 요약부터 보여주고, 날짜·상위 Todo·카테고리는 세부 정보에서 펼친다. 편집 화면의 날짜 수정 기능은 유지한다.
- Today 시간 합계를 축소하고, 할 일·일정·활성 세션이 없을 때 주요 행동은 Todo 추가로 연결했다.
- 월간 일정 밀도 점, 주간 일정 선택 상세와 하루 보기 이동을 추가했다.
- Stats의 계획 초과·미달·계획 없음 문구를 구분했다.
- 기존 react-native-svg를 재사용했다. 추가 의존성은 없다.

## 검증

- TypeScript 검사 및 Web export 실행.
- iOS Simulator: Todo 펼침·접기, 빠른 입력과 세부 정보 확장, 둥근 모달, 주간 7열 및 선택 일정 상세를 확인했다.
- 기존 Web export의 expo-notifications 서버 렌더링 localStorage 경고는 별도 이슈로 남는다. export는 성공한다.

## 남은 일

- Android와 iOS 실제 기기에서 키보드, 글자 크기 확대, 시스템 뒤로가기 QA는 사용자 단계에서 진행한다.
