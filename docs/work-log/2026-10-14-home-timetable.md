# 2026-10-14 — 홈 오늘 시간표

## 목표

Today 화면에서 사용자가 오늘의 모든 계획을 한눈에 볼 수 있게 한다.

## 변경

- 집중 요약 아래에 `오늘 시간표` 섹션을 추가했다.
- 각 Schedule Block의 시작·종료 시각, 제목, 연결 Todo를 표시한다.
- 일정 화면과 같은 제한된 색 규칙으로 블록을 구분한다.
- 현재 진행 시간대에는 `진행 중` 상태를 표시한다.
- 일정이 없을 때는 일정 탭에서 시간을 배치하도록 안내한다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과
- `cd frontend && npx expo export --platform web` 통과

## 남은 일

- 실제 기기에서 많은 일정이 있는 날의 홈 스크롤 길이와 작은 시간 텍스트를 확인한다.
