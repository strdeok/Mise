# 2026-10-17 — 일정 시간표 가독성

## 목표

계획 3단계에 따라 월간·주간·일간 일정 정보의 시간 위계와 연결 상태를 더 빠르게 읽히게 한다.

## 변경

- 월간 의제에서 선택 날짜를 PrepLabel로 표시하고, 시작 시간·제목·전체 시간 구간·연결 Todo를 구분했다.
- 월간 달력 위에 있던 이번 달 블록 수와 배치 일수 요약을 제거했다.
- 주간 일정은 기존 7열과 짧은 제목 표현을 유지하되, 선택 후 아래 영역에 날짜·시간 구간·제목·Todo 연결을 표시한다.
- 일간 일정 상세에 준비 라벨, 고정 폭 시간 표기, Todo 연결 상태를 추가했다.
- 드래그 미리보기, 일정 선택·수정·삭제, 기존 저장 동작은 유지했다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과. Expo 알림 모듈의 웹 서버 렌더링 `localStorage` 경고가 출력됐지만 번들과 정적 경로 내보내기는 완료됐다.
- 브라우저 월간·주간·일간 화면을 확인했다. 월간 의제에는 시작/종료 시간과 Todo 연결 여부가, 주간 선택 영역에는 전체 시간 구간과 Todo 연결이 보인다. 일간 블록에는 시작/종료 시간과 연결 Todo가 표시된다.
- 후속 정리에서 월간 달력 상단 요약을 제거하고, 브라우저에서 달력이 헤더 바로 아래에 배치되는 것을 확인했다.
- Impeccable 감지 결과 문제가 없었다 (`[]`).

## 남은 일

- 실제 일정 짧은 블록의 줄바꿈과 드래그 미리보기를 기기에서 확인한다.
- 실제 iOS·Android 기기 QA는 사용자가 진행한다.
