# 2026-10-17 — Structured 일간 시간축 레퍼런스 재반영

## 목표

기존 일간 화면을 Structured 원본과 다시 비교해 일정 길이와 시간 흐름을 더 정확히 표현한다.

## 변경

- 시간마다 전체 폭을 가로지르던 격자선을 제거하고 시간 라벨을 남겼다.
- 일정 표시 중앙을 지나는 얇은 세로선을 추가해 일정 사이의 흐름을 이었다.
- 15분 이하의 짧은 일정은 원형, 그보다 긴 일정은 길이에 비례하는 세로 캡슐로 나타낸다.
- 흑백 토큰과 기존 일정 선택·드래그 동작을 유지했다.
- SDD의 일간 시간표 기준을 실제 Structured 레퍼런스와 맞췄다.

## 확인

- TypeScript 검사 통과.
- Expo 웹 내보내기 통과.
- 브라우저 일간 화면에서 연결 레일, 원형/캡슐형 일정 표시와 시간 라벨을 확인했다.

## 남은 일

- 실제 기기에서 드래그 감도와 시간축 경계의 일정 추가를 확인한다.
