# 2026-10-17 — Structured 스타일 일간 시간표

## 목표

사용자가 선호한 Structured의 일간 일정을 Mise의 흑백 준비표와 시간표 표현으로 옮긴다.

## 변경

- 일간 상단에 주간 날짜 탐색 줄을 추가했다. 날짜를 누르면 해당 날짜의 일정으로 이동한다.
- 왼쪽 시간 눈금과 세로 레일, 일정 시작 노드, 오른쪽의 큰 일정 제목과 시간 구간을 적용했다.
- 기존 시간 비례 배치, 빈 시간 눌러 추가, 길게 눌러 드래그 이동 및 5분 단위 저장을 유지했다.
- 30분 미만 일정은 제목을 우선 표시하고, 눌렀을 때 상세에서 전체 구간을 확인한다.
- SDD와 단계 계획의 일간 디자인 규칙을 갱신했다. 새 의존성은 추가하지 않았다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과.
- Impeccable UI 감지 결과 `[]`.
- 브라우저에서 360px·390px 폭을 확인하고 날짜 줄, 시간축, 일정 제목·구간 표시를 점검했다.

## 남은 일

- 실제 iOS·Android 기기에서 날짜 탐색, 짧은 일정 선택, 드래그 이동과 Safe Area를 확인한다.
