# 2026-10-17 — 일간 시간축 표시 범위 조정

## 목표

Structured의 실제 길이 기반 타임라인을 살리면서 비어 있는 하루 전체를 화면에 펼치지 않는다.

## 변경

- 일간 일정을 소요 시간에 비례한 세로 캡슐형 컴포넌트로 표시한다.
- 캡슐의 높이가 실제 일정 길이를 반영하고, 시작·종료 시간과 소요 시간도 옆에서 읽을 수 있다.
- 보이는 시간축을 첫 일정 시작 시각의 정시부터 마지막 일정 종료 30분 뒤까지로 제한했다.
- 상단 날짜 줄과 흑백 레일을 유지하고 빈 영역을 누르면 해당 시간에 일정을 추가한다.
- 드래그는 기존 5분 단위로 시간을 이동한다.
- SDD와 화면 계획을 표시 범위 규칙에 맞게 수정했다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과.
- Impeccable UI 감지 결과 `[]`.
- 브라우저에서 2개 일정의 간격·길이·제목, 빈 날짜 안내, 날짜 선택을 확인했다.

## 남은 일

- 실제 기기에서 드래그 감도, Safe Area와 시간축 경계에서 일정 추가를 확인한다.
