# 2026-10-17 — Today 집중·계획 시간 요약

## 목표

Today 화면에서 실제 집중 시간과 계획 시간을 더 쉽게 비교하도록 요약 영역을 정리한다.

## 변경

- 실제 집중과 계획 시간을 좌우 두 칸에 같은 위계로 표시한다.
- 두 값 아래에 흑백 진행 막대를 두어 계획 대비 실제 비율을 시각적으로 표시한다. 별도의 비율 문구는 넣지 않는다.
- 값이 없는 계획 시간은 `계획 없음` 대신 `없음`으로 간단히 표기한다.
