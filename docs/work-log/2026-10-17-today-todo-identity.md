# 2026-10-17 — Today와 Todo 작성 화면 정리

## 목표

준비표·시간축 방향을 Today와 Todo 작성의 첫 기준 화면에 반영한다.

## 변경

- Today 상단에 `오늘의 준비` 라벨을 두고, 현재 일정·다음 일정·지금 할 일 맥락을 둥근 준비 라벨로 구분했다.
- Todo 작성에서 제목 다음에 일정 날짜와 시작·종료 시간을 배치하고, 예상 소요 시간은 부가 항목으로 뒤로 옮겼다.
- 선택된 시간은 공용 `TimeValue`로 표시한다. 기존 날짜/시간 저장 액션과 데이터 구조는 유지했다.
- 단계 계획 문서의 진행 상태를 갱신했다.

## 검증

- `cd frontend && npx tsc --noEmit` 통과.
- `cd frontend && npx expo export --platform web` 통과. Expo 알림 모듈의 localStorage 서버 렌더링 경고는 출력됐으나 웹 번들과 정적 경로 내보내기는 완료됐다.
- UI 정적 감지에서 결과 없음.
- Today와 Todo 작성 화면을 웹 브라우저에서 확인했고, 웹 시간 선택기에서 키보드 아이콘이 표시되는 것을 확인했다.

## 남은 일

- 360dp·390dp 폭별 화면 확인과 iOS·Android 시간 선택기 QA.
- 실제 기기 QA는 사용자가 진행한다.
