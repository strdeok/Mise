# 2026-10-17 — 주간 의제와 일간 시간축 재구성

## 목표

주간은 한 주의 일정 제목과 시간 구간을 읽기 쉽게, 일간은 실제 시간 배치를 선명하게 보여준다.

## 변경

- 사용자 승인한 레퍼런스 방향을 SDD에 먼저 반영했다. 기존 주간 7열 격자 규칙을 날짜 탐색과 날짜별 의제로 변경했다.
- 주간 상단 날짜는 해당 날짜 섹션으로 이동한다. 날짜별 추가 버튼은 해당 날짜의 일정 작성을 연다. 빈 날짜는 한 줄로 표시한다.
- 일정 행에서 시작·종료 시간, 전체 제목과 소요 시간을 표시한다. 같은 제목의 연결 Todo는 반복 표시하지 않는다.
- 주간과 일간에서 같은 상세 구성요소로 수정·삭제·집중 시작 및 미연결 Todo 선택을 처리한다.
- 일간 시간축은 시간당 90dp로 확대하고 제목 16px, 시간 구간 12px, 둥근 모서리와 얇은 선을 적용했다. 첫 일정 주변부터 연다.
- 빈 시간 선택과 드래그 이동·5분 단위 스냅·미리보기의 좌표 계산을 새 시간 축척에 맞췄다. 시간 비례와 저장 형식은 유지한다.
- 의존성 추가 없음.

## 검증

- TypeScript 검사와 Expo 웹 내보내기 통과. 기존 Expo 알림 모듈의 웹 서버 렌더링 localStorage 경고는 출력된다.
- 브라우저에서 주간 날짜 이동, 일정 상세 열기·닫기, 일간 시간 구간과 중복 Todo 생략을 확인했다.
- 360dp 주간과 390dp 일간 화면에서 날짜 탐색·제목·시간 구간·빈 날짜 행을 확인했다.
- Impeccable UI 감지 결과 `[]`.

## 남은 일

- 실제 기기에서 짧은 일정 터치, 일간 드래그·5분 스냅, Safe Area와 모달 조작 QA는 사용자가 진행한다.
